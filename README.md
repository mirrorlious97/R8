# 外刊阅读器（小白版上手）

你问得非常好：**不用一个个下载文件**。

## 你只要做这 3 件事

1. 把整个项目下载到你的电脑（一个文件夹）。
2. 在这个文件夹里打开终端。
3. 按下面命令启动。

---

## 第 0 步：先安装 Node.js

- 去官网下载安装：<https://nodejs.org>
- 安装完成后，打开终端输入：

```bash
node -v
```

看到版本号（比如 `v20.x.x`）就说明安装成功。

---

## 第 1 步：拿到项目（不要一个个文件下载）

你有两种方式，任选其一：

### 方式 A（推荐，最简单）
在代码仓库页面点 **Code -> Download ZIP**，下载后解压。

### 方式 B（会一点命令行）
```bash
git clone <你的仓库地址>
cd R8
```

---

## 第 2 步：配置你的 OpenAI Key

> 你必须有自己的 API Key，不要泄露给别人。

在项目根目录新建一个 `.env` 文件，内容如下：

```env
OPENAI_API_KEY=你的Key
OPENAI_MODEL=gpt-5.2
PORT=4173
```

---

## 第 3 步：启动

在项目根目录执行：

```bash
node server.mjs
```

看到类似输出：

```text
Reader app running at http://127.0.0.1:4173
```

然后浏览器打开：

- <http://127.0.0.1:4173>

---

## 你之前“打不开 127.0.0.1:4173”的原因

`127.0.0.1` 是“你自己这台电脑”。

所以必须满足：

- 你在**同一台电脑**上运行了 `node server.mjs`
- 终端没有报错、没有关闭
- 端口没有被占用

如果你在手机或另一台电脑打开这个地址，肯定打不开。

---

## 一句话理解功能

- 粘贴外刊英文
- 自动按段落显示
- 每段可点“查看翻译”（调用 `gpt-5.2`）
- 六级 / 考研词会荧光高亮

---

## 常见报错（小白版）

### 1) `Missing OPENAI_API_KEY on server`
你没有配置 Key。检查 `.env` 是否创建、变量名是否写对。

### 2) 终端提示端口占用
把 `.env` 里的 `PORT=4173` 改成其他端口，比如 `PORT=5173`，然后重启。

### 3) `node: command not found`
Node.js 没装好，重新安装并重启终端。
